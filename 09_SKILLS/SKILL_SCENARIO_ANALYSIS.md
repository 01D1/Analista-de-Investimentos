# Skill: Scenario Analysis

## Objetivo
Construir visões alternativas coerentes do futuro para balizar o range de valor de um ativo.

## Estrutura padrão

| Cenário | Probabilidade | Premissa central |
|---|---|---|
| Otimista | 25% | Aceleração de crescimento + expansão de margem |
| Base | 50% | Crescimento histórico + margem estável |
| Pessimista | 25% | Desaceleração + compressão de margem |

## Processo

### Passo 1 — definir o gatilho
Qual é a variável mais incerta? (regulação, macro, concorrência, gestão)

### Passo 2 — construir narrativa
Cada cenário deve ter uma história coerente, não apenas números.

### Passo 3 — modelar as premissas
Alterar receita, margem, capex e capital de giro de forma consistente com a narrativa.

### Passo 4 — calcular valor ponderado
Valor esperado = Σ (probabilidade × valor do cenário)

## Saída
- Tabela: Preço justo por cenário
- Range implícito
- Valor esperado ponderado

## Erros Comuns
- Cenário pessimista irrealisticamente brando
- Probabilidades não somam 100%
- Premissas de cenários não são coerentes entre si
