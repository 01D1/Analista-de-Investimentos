# Índice de Setores

Cada setor deve conter: dinâmica competitiva, principais métricas, riscos estruturais, ciclo econômico, indicadores-chave, comparáveis e armadilhas analíticas.

---

| Setor | Arquivo | Métricas-Chave |
|---|---|---|
| Bancos | [[Bancos]] | P/VP, ROE, NIM, inadimplência |
| Energia Elétrica | [[Energia]] | RAB, EBITDA regulatório, concessão |
| Saneamento | [[Saneamento]] | RAB, CAPEX regulatório, coverage |
| Varejo | [[Varejo]] | SSS, margem bruta, giro de estoque |
| Educação | [[Educacao]] | Ticket, inadimplência, EBITDA ajustado |
| Saúde | [[Saude]] | Sinistralidade, receita por leito, EBITDA |
| Commodities | [[Commodities]] | Preço de commodity, custo/t, EBITDA/t |
| Tecnologia | [[Tecnologia]] | ARR, Churn, NRR, LTV/CAC |
| Seguros | [[Seguros]] | Combined ratio, float, ROE, sinistralidade |
| Construção Civil | [[Construcao]] | VSO, VGV, margem bruta, estoque |
| Transporte e Logística | [[Logistica]] | EBITDA/t, margem operacional, capex |
| Telecomunicações | [[Telecom]] | ARPU, churn, EBITDA, capex/receita |

---

## Modelo de Nota de Setor

Cada arquivo de setor deve conter:

```markdown
## Dinâmica Competitiva
## Principais Métricas
## Drivers de Demanda
## Sazonalidade
## Riscos Estruturais
## Ciclo Econômico
## Armadilhas Analíticas
## Framework de Valuation Específico
## Peers de Referência
```
