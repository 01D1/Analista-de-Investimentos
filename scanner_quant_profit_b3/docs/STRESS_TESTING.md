# Stress Testing

Stress tests estimam perda hipotética sob choques definidos.

Cenários iniciais:

- `EQUITY_SHOCK_5`
- `EQUITY_SHOCK_10`
- `EQUITY_SHOCK_20`
- `VOL_SPIKE`
- `LIQUIDITY_SHOCK`
- `GAP_DOWN`
- `BLACK_SWAN`

Também há stress simples por ativo com choques de -2%, -5%, -10% e -20%.

Os resultados são analíticos e dependem do valor de posição informado pelo sizing.
