## 1. Contexto

A M017-S02.5 (CVM Full Dataset Audit) identificou dois mapeamentos críticos incorretos em
`config/cvm_codes.yaml`. O CD_CVM mapeado para EQTL3 e VAMO3 pertencia a **empresas
completamente diferentes**, contaminando todos os dados históricos dessas posições em `cvm_statements`.

## 7. Nota técnica — Bug em parse_and_store()

Durante a M017-S02.6, identificado que `src/ingestion/cvm_downloader.py::parse_and_store()`
falha com `KeyError: 'CD_CVM'` ao processar o arquivo metadata `dfp_cia_aberta_{year}.csv`
(sem coluna `CD_CVM`), pois `download_dfp()` retorna todos os CSVs do diretório.

**Workaround aplicado:** reingestão direta via `run_reingest_from_filtered.py`.
**Ação recomendada para M017-S03:** adicionar `if 'CD_CVM' not in df.columns: continue`
no loop de `parse_and_store()`.
