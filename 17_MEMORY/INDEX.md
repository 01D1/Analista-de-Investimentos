## Como Registrar um Aprendizado

Adicionar ao arquivo correspondente com este formato:

```
### [Data] — [Título do aprendizado]
**Contexto:** onde/como isto foi aprendido
**Aprendizado:** o que ficou
**Aplicação:** quando usar este conhecimento
```
