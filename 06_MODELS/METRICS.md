# Metricas Financeiras

Indicadores padrao utilizados na analise de empresas.

## Rentabilidade

- **ROE** (Return on Equity) — Lucro liquido / Patrimonio liquido
- **ROIC** (Return on Invested Capital) — NOPAT / Capital investido
- **ROA** (Return on Assets) — Lucro liquido / Ativos totais

## Margens

- **Margem Bruta** — Lucro bruto / Receita liquida
- **Margem EBITDA** — EBITDA / Receita liquida
- **Margem Liquida** — Lucro liquido / Receita liquida
- **Margem Operacional** — EBIT / Receita liquida

## Alavancagem

- **Divida Liquida / EBITDA** — Principal indicador de endividamento
- **Divida Bruta / PL** — Relacao divida/equity
- **Cobertura de Juros** — EBITDA / Despesas financeiras

## Geracao de Caixa

- **FCF** (Free Cash Flow) — Fluxo de caixa operacional - Capex
- **FCF Yield** — FCF / Market Cap
- **Conversao de Caixa** — FCF / Lucro liquido

## Valuation

- **P/L** — Preco / Lucro
- **P/VP** — Preco / Valor patrimonial
- **EV/EBITDA** — Enterprise Value / EBITDA
- **Dividend Yield** — Dividendos por acao / Preco

## Uso

Metricas devem ser calculadas de forma padronizada pelo Financial Engine.
Comparacoes so sao validas entre empresas do mesmo setor.
