# Comunicação com o Mercado

> Avaliação da qualidade e transparência da comunicação das empresas com investidores. Comunicação de qualidade é proxy de boa governança e facilita a análise.

---

## Por que Comunicação Importa

1. **Reduz assimetria de informação** — acionistas tomam decisões com mais informação
2. **Sinaliza integridade do management** — quem comunica mal quando vai bem, esconde quando vai mal
3. **Facilita valuation** — releases detalhados permitem modelagem mais precisa
4. **Afeta custo de capital** — melhor comunicação = menor prêmio de risco = menor custo de equity

---

## Canais de Comunicação

### Obrigatórios (CVM)

| Canal | O que contém | Prazo |
|---|---|---|
| ITR (Informe Trimestral) | DRE/BP/DFC trimestral + notas explicativas | 45 dias após fechamento |
| DFP (Demonstrações Financeiras Padronizadas) | DRE/BP/DFC anual + notas completas | 3 meses após fechamento |
| Formulário de Referência | Governança, remuneração, riscos, RPTs | Anual + atualização em IPO |
| Fatos Relevantes | Eventos materiais que impactam a decisão de investimento | Imediato após ocorrência |
| Comunicados ao Mercado | Eventos relevantes mas não qualificados como fato relevante | Discricionário |

### Voluntários (Melhores Práticas)

| Canal | O que contém | Frequência ideal |
|---|---|---|
| Release de Resultados | Análise detalhada dos números trimestrais/anuais | Trimestral |
| Conference call / Earnings call | Management responde analistas | Trimestral |
| Investor Day | Estratégia de longo prazo, metas | Anual |
| Relatório Anual | Narrativa completa + ESG + governança | Anual |
| Website de RI | Central de informações | Permanente |
| Apresentação para investidores | Pitch deck institucional | Contínuo |

## Avaliação da Qualidade do Release de Resultados

### Dimensões de Análise

**1. Conteúdo (o que está lá)**
- [ ] Receita por segmento/produto
- [ ] Margens por segmento
- [ ] Evolução do mix
- [ ] KPIs operacionais relevantes (inadimplência para bancos, SSS para varejo, etc.)
- [ ] Variação YoY e trimestral com explicação de drivers
- [ ] Guidance (quando fornecido) — atual vs. anterior vs. realizado
- [ ] Reconciliação de ajustes ("EBITDA ajustado" com detalhamento)

**2. Qualidade (como é apresentado)**
- [ ] Linguagem clara e objetiva (sem excesso de marketing)
- [ ] Itens negativos apresentados com mesma clareza que positivos
- [ ] Comparação consistente com períodos anteriores (sem mudança de métrica quando desfavorável)
- [ ] Tabelas numéricas precisas, reconciliadas com a DFP
- [ ] Sem "cherry picking" de métricas ("receita cresceu 20%... [em segmento X, excluindo Y]")

**3. Tempestividade**
- [ ] Publicação próxima ao fechamento do período (não 45 dias depois)
- [ ] Divulgação de fatos relevantes imediatamente (não "consertar" antes de anunciar)

## Avaliação da Conference Call

### Sinais positivos
- Management responde perguntas difíceis diretamente
- CEO e CFO participam pessoalmente
- Formato permite perguntas abertas de analistas externos
- Transcrição disponível para acionistas sem acesso à call

### Sinais negativos
- Respostas evasivas a perguntas sobre guidance não cumprido
- IR responde por "escrito" perguntas sobre irregularidades
- Perguntas filtradas ou censuradas
- Management cancela ou atrasa calls sem motivo claro
- Linguagem muito "corporativa" sem substância

## Guidance — Análise de Track Record

O guidance é o teste definitivo de honestidade e previsibilidade do management.

### Como compilar histórico de guidance

```
| Ano | Métrica | Guidance inicial | Revisão | Realizado | Erro % | Direção |
|-----|---------|-----------------|---------|-----------|--------|---------|
| 2023 | EBITDA | R$ 5–6 bi | R$ 4.5–5.5 bi | R$ 5.1 bi | −2% | Para baixo |
| 2024 | | | | | | |
| 2025 | | | | | | |
```

**Interpretação:**
- Erro consistente para cima (sempre atingindo) → muito conservador (subestime a realidade)
- Erro consistente para baixo (nunca atingindo) → excesso de otimismo ou manipulação de expectativas
- Melhores empresas: guidance estreito, atingido com pequenas variações

## Qualidade do Auditor

### Hierarquia de qualidade (estimativa)
1. Big Four (Deloitte, PwC, KPMG, EY) — maior credibilidade global
2. Grant Thornton, BDO — qualidade intermediária, boa para mid-cap
3. Firmas menores especializadas — aceitável para small caps com nicho específico
4. Firmas desconhecidas ou sem histórico — sinal de alerta

### O que verificar
- Há rodízio de auditor? (CVM recomenda a cada 5 anos para companhias abertas)
- Há ressalva na opinião? Tipo: ênfase, opinião modificada, abstenção?
- Auditor trocou após divergência com management?
- Comitê de auditoria tem acesso direto ao auditor externo (sem filtro do CFO)?
