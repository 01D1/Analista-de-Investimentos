# Morning Call

Template para resumo diario de mercado.

## Estrutura

### Mundo
- Principais indices (S&P 500, Nasdaq, Stoxx 600, Nikkei)
- Eventos relevantes overnight
- Decisoes de bancos centrais

### Brasil
- Ibovespa, dolar, juros futuros
- Noticias politicas e economicas relevantes
- Dados macro do dia (se houver)

### Commodities
- Petroleo (Brent/WTI)
- Minerio de ferro
- Ouro
- Agricolas (soja, milho) quando relevante

### Impactos
- Setores mais afetados
- Empresas com eventos relevantes (resultados, M&A, regulacao)
- Conexoes macro-micro

## Regras

1. Objetivo: informar, nao opinar
2. Maximo 1 pagina
3. Sempre incluir data
4. Fontes verificaveis
