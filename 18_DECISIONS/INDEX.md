# Registro de Decisões

Toda decisão importante de arquitetura, metodologia ou processo deve ter uma entrada aqui.

---

## Formato de Arquivo

```
AAAA-MM-DD_decisao_[descricao_curta].md
```

---

## Template de Decisão

```markdown
# Decisão: [Título]

**Data:** AAAA-MM-DD
**Status:** Ativa / Revisada / Revogada

## Contexto
Por que esta decisão precisava ser tomada?

## Decisão
O que foi decidido.

## Alternativas Consideradas
1. Opção A — por que não foi escolhida
2. Opção B — por que não foi escolhida

## Motivação
Por que esta opção foi a escolhida.

## Impacto Esperado
O que muda com esta decisão.

## Riscos
O que pode dar errado com esta escolha.

## Revisão
Quando / como esta decisão deve ser revisada.
```
