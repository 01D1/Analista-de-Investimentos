# Vault — Plataforma de Inteligência Financeira Automatizada

> [!abstract] O que é este vault?
> Este é o **núcleo operacional e cognitivo** de um projeto de modelagem financeira, valuation, pesquisa e automação de dados empresariais em Python. Não é apenas um lugar para guardar notas — é um sistema que ensina agentes de IA e operadores humanos a pensar, pesquisar, validar, modelar, documentar e entregar análises com padrão profissional.

## Síntese da Arquitetura Mental

> **Dados → Validação → Estruturação → Modelo → Valuation → Tese → Output → Aprendizado**

## As 5 Camadas do Projeto

```
Camada 1 — CONHECIMENTO   Vault, notas, setores, empresas, prompts, decisões
Camada 2 — DADOS          Coletores, parsers, armazenamento, schemas, ETL
Camada 3 — MODELAGEM      Modelos históricos, projeções, indicadores, valuation
Camada 4 — INTELIGÊNCIA   Agentes, heurísticas, detecção de inconsistências
Camada 5 — ENTREGA        Relatórios, dashboards, research, resumos executivos
```

## Stack Tecnológica

- **Obsidian** — conhecimento e linking
- **GitHub** — versionamento
- **Python** — ingestão, tratamento, modelagem
- **DuckDB / PostgreSQL** — base estruturada
- **Parquet** — camadas intermediárias
- **Streamlit** — dashboards rápidos
- **Pydantic** — contratos de dados
- **Pytest** — testes
