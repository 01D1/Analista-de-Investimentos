# Intelligence System

Sistema integrado de análise financeira, macroeconômica e geração de conteúdo.

## Objetivo
- analisar empresas
- processar notícias globais
- gerar teses de investimento
- produzir conteúdo analítico

## Componentes
1. Financial Engine
2. Macro News Engine
3. Intelligence Layer
4. Content Engine

## Princípios
- separação de responsabilidades
- rastreabilidade
- validação obrigatória
- reprodutibilidade
