# Fluxo Completo do Analista/Trader

> Sistema completo de análise de investimentos inspirado em:
> - **Aswath Damodaran** — valuation rigoroso
> - **Benjamin Graham** — value investing e margem de segurança
> - **Paul Tudor Jones** — timing, risco e execução

---

## Pipeline completo

```
EXTRAÇÃO → ANÁLISE → PROJEÇÃO → VALUATION → MISPRICING → GRÁFICO → ENTRADA → GESTÃO
```

| Etapa | Skill | Saída |
|---|---|---|
| EXTRAÇÃO | [[SKILL_EXTRACAO_FINANCEIRA]] | Dados limpos e padronizados |
| ANÁLISE | [[SKILL_LEITURA_DRE]] · [[SKILL_ANALISE_DE_DRIVERS_OPERACIONAIS]] · [[SKILL_UNIT_ECONOMICS]] | Entendimento do negócio |
| PROJEÇÃO | [[SKILL_PROJECAO_FINANCEIRA]] · [[SKILL_MODELO_3_STATEMENTS]] · [[SKILL_SCENARIO_ANALYSIS]] | Modelo 5–10 anos com cenários |
| VALUATION | [[SKILL_CONSTRUCAO_DCF]] · [[SKILL_MULTIPLOS]] · [[SKILL_SENSITIVITY_ANALYSIS]] | Valor justo + range |
| MISPRICING | [[SKILL_MISPRICING_DETECTION]] · [[SKILL_LEITURA_DE_MERCADO]] · [[SKILL_ANALISE_MACRO]] | Divergência fundamento vs. preço |
| GRÁFICO | [[SKILL_LEITURA_DE_GRAFICO]] · [[SKILL_TENDENCIA]] · [[SKILL_SUPORTE_RESISTENCIA]] | Zona de entrada técnica |
| ENTRADA | [[SKILL_PRICE_ACTION]] · [[SKILL_VOLUME_E_FLUXO]] · [[SKILL_ENTRADA_SAIDA]] | Setup operacional com stop |
| GESTÃO | [[SKILL_RISCO_RETORNO]] · [[SKILL_ALOCACAO_DE_CAPITAL]] · [[SKILL_TOMADA_DE_DECISAO]] | Posição dimensionada e monitorada |

---

## Diferencial do sistema

Pouquíssimos profissionais dominam os 4 pilares simultaneamente:

| Pilar | Capacidade |
|---|---|
| ✅ Analista fundamentalista | Entende o negócio em profundidade |
| ✅ Modelador | Traduz fundamento em números defensáveis |
| ✅ Estrategista | Identifica quando o mercado está errado |
| ✅ Trader | Executa com disciplina, risco definido e timing preciso |
