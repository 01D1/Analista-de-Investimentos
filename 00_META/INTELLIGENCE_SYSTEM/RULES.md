# Rules

1. Nunca misturar dado bruto com interpretação.
2. Toda análise deve ter fonte.
3. Toda premissa deve ser documentada.
4. Todo output importante deve passar por validação.
5. Toda mudança relevante deve ser rastreável.
6. Notícias e dados financeiros devem permanecer em camadas separadas.
7. A tese de investimento deve sempre explicitar riscos e fatores de invalidação.
